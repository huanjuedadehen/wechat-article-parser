# 正文转换规则

[返回 README](../README.md) · [API 参考](api.md) · [开发指南](development.md)

本文说明 Markdown 和图片列表的保留规则，以及页面模板的识别方式。
解析器从页面 HTML 和已知脚本数据结构提取内容，不执行 JavaScript，也不渲染页面截图。

## 文字与排版

- 保留可提取的正文文字、段落、图片和普通正文链接，转换为 Markdown；不还原原网页的样式和交互布局。
- 富文本中的代码保留缩进与换行，代码中的不换行空格转为普通空格；表格中的管道符进行转义。
- 展开无格式作用的 `span`，合并重复嵌套的加粗、斜体和删除线，避免编辑器生成的冗余标签导致递归超限。
- 纯文本和分享附言保留换行。纯文本、全屏布局分支的标题超过 50 字符时，优先取不超过 50 字符的首句，否则截取前 30 字符。

## 图片与 SVG

| 内容 | 输出规则 |
|---|---|
| 静态正文图片 | 保留图片链接 |
| 轮播图片 | 保留各页图片 |
| SVG 缩放动画中的图片 | 保留图片，去掉缩放效果 |
| 明确识别的 SVG 快速逐帧序列 | 仅保留首帧 |
| 无法确认的帧序列、CSS / JavaScript 动画 | 保留可提取的图片，不执行动画 |
| SVG 延迟显示、点击展开的内容 | 直接输出可提取的文字和图片 |
| SVG 跳转链接 | 去掉链接，保留其中的文字或图片 |
| SVG 遮罩、空热区、动画控制和无来源空图片 | 不生成正文 |

富文本图片支持 `src`、`data-src`；SVG 图片支持 `background`、`background-image` 中的
HTTP(S) 地址（有引号或无引号）、`foreignObject` 内的图片，以及 `<image href="…">` / `<image xlink:href="…">`。
微信 CDN 图片地址会进行规格标准化，提取结果不保证与原始 URL 完全相同。
这里只返回链接，不下载图片文件，也不对 GIF 等图片文件解码、截取首帧。

`images` 收集最终保留的正文图片并按顺序去重；除已识别的帧序列缩减外，富文本 Markdown 保留原文重复图片。
小程序封面、头像和红包封面预览图按下文规则排除。

SVG `<text>` / `<tspan>` 和 `foreignObject` 中的 HTML 正文按原顺序保留。
定义、裁剪、遮罩、辅助标题/说明及路径等几何元素不作为正文输出。
这些规则按标签和结构处理，**不会根据画面语义判断一张图片是否为纯装饰**，也不把 SVG 矢量图形栅格化为图片。

### 快速逐帧序列的识别条件

当前仅对可确认的结构缩减图片，规则包括：

- 图片尺寸相同，按横向或纵向等距排列；循环的 `discrete` 平移动画按对应坐标依次切换。
- 合并连续重复坐标后至少有 3 个位置，总时长除以位置数大于 0 且不超过 0.2 秒。
- 支持动画序列末尾分号、重复坐标停留，以及通过最近 SVG 的 `viewBox` 或明确尺寸解析的百分比宽高。
- 背景 SVG 未设置自身位置和尺寸时，可读取直接外层 `foreignObject` 的几何信息。
- 帧间距大于图片尺寸时，须确认视口能容纳当前帧且不会展示相邻帧；未播放的尾图仅在视口恰好容纳一帧时省略。
- 存在不支持的额外变换、关键时间点或无法确认的几何结构时，不缩减帧序列。

## 微信组件与占位提示

以下规则用于富文本正文中的相应组件。组件文字按其正文位置输出；
仅有组件提示且关键元数据完整时，`is_valid` 也可能为 `True`。

| 内容 | Markdown 输出 | 范围说明 |
|---|---|---|
| 仅有视频号视频卡片或微信视频 iframe | 这是一篇纯视频内容。 | 不提取视频文件 |
| 仅有付费预览占位 | 这是一篇付费内容，正文需付费后查看。 | 保留公开元数据；可见预览正文正常提取 |
| 仅有商品广告卡片（`mp-common-cpsad`） | 这是一篇商品推荐内容。 | 已有文字和图片仍正常提取，不表示获取了商品详情 |
| 公众号推荐卡片（`mp-common-profile`） | `**公众号名称**：简介` | 缺少名称或简介时，仅输出已有字段 |
| 小程序卡片（`mp-common-miniprogram`） | 加粗标题、`小程序：名称`、请在微信中打开小程序查看内容。 | 缺少标题或名称时省略对应段落；不保留封面、头像和内部路径链接 |
| 红包封面（`mp-common-redpacket`） | 红包封面，请在微信中查看。 | 不展示名称、预览图或领取链接，不判断是否仍可领取 |
| 投票（`mp-common-vote`） | 加粗题目及选项列表 | 支持多题和多个组件；不输出票数，不推断单选或多选 |

投票数据缺失或异常时，保留组件已有文字；没有文字则输出“投票内容，请在微信中查看。”。
解析结果不代表完整投票内容或实时结果。

`article_is_paid` 独立于正文内容：有可见预览或可访问正文的付费文章仍会标记为 `True`。
识别来源为页面全局或 `window.cgiDataNew` 直接属性中的 `is_pay_subscribe`，以及正文中的 `mp-pay-preview-filter`。

## 页面模板与回退

解析优先读取全局 `item_show_type`：`0` 图文、`5` 视频、`7` 音频、`8` 图片轮播、`10` 文字。
音频与视频共用文字附言提取逻辑。展示类型的原始值和语义值分别写入
`article_item_show_type` 和 `article_display_type`。

字段缺失、未知或优先分支未提取到正文时，依次尝试：

| 顺序 | 模板 | HTML 特征 |
|---|---|---|
| 1 | 标准富文本 | `div.rich_media_content` |
| 2 | 转载式 | `div.original_page` |
| 3 | 纯文本 | `p#js_text_desc` |
| 4 | 视频分享 | `div#js_common_share_desc_wrap` |
| 5 | 图片轮播 | `div.share_media_swiper_content` |
| 6 | 全屏布局 | `div#js_fullscreen_layout_padding` |

每个分支使用独立候选结果，只有提取到正文才采用；失败分支不影响后续分支的标题、图片和元数据。
展示类型由 `item_show_type` 映射，不根据回退模板重新推断，因此未知类型也可能提取到正文。
视频、音频无附言时仍可通过最终元数据提取返回有效结果。

全屏文字只读取 `cgiDataNew.text_page_info` 的直接属性：优先使用 `content_noencode`，为空或没有可见正文时尝试 `content`。
外层或嵌套卡片中的同名字段不作为正文。图片和文字可位于不同脚本中，转义引号和换行会解码。
图文通过全屏脚本回退提取正文时，也会读取富文本元数据。
